# Fidusia — Tienda online de skincare y cosmética
# LINK: https://marvar1979.github.io/Fiducia/


Proyecto front-end responsive desarrollado con HTML5, CSS3, Bootstrap 5, Bootstrap Icons, JSON y JavaScript puro.


## Funciones incluidas
- Home responsive con identidad rosa, blanca y dorada.
- Catálogo con búsqueda, filtros y ordenamiento.
- Vista rápida de producto.
- Carrito con cantidades, subtotal y checkout simulado.
- Lista de favoritos.
- Generador simple de rutina por necesidad de la piel.
- Newsletter y formulario de contacto demo.
- Persistencia local de carrito y favoritos con localStorage.
- Inicio de sesión demo por roles con sessionStorage.
- Panel Administrador con métricas y pedidos.
- Panel Ventas con métricas y pedidos.
- Panel Almacén con inventario.
- Panel Cliente con resumen de cuenta.
- JSON de productos y credenciales demo.


## Nota visual
La propuesta toma inspiración general de tiendas de belleza como Velvet Beauty en la organización de navegación, catálogo, categorías y módulos promocionales, sin copiar su diseño ni su contenido exacto.
